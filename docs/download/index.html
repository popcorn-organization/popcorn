TV

Android TV, Google TV and Fire TV.

  1. On the TV, get Downloader from its app store.
  2. Let Downloader install apps. You only do this once.
    How?

    Google TV and Android TV: in Settings → System → About, press OK on Android TV OS build seven times. Then in Settings → Apps → Security & restrictions → Unknown sources, turn on Downloader.

    Fire TV: in Settings → My Fire TV → About, press OK on your Fire TV’s name seven times. Then in My Fire TV → Developer options → Install unknown apps, turn on Downloader.

  3. Open Downloader, type this address, then choose Install: popcorn-organization.github.io/popcorn/tv
